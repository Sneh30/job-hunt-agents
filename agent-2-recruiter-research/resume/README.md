# Resume sources (not included)

This repo intentionally ships no resume. Put your own source here:

- `resume.tex` — the LaTeX source the agent compiles and attaches after review
- `resume_profile.md` — a machine-readable fact summary the agent must treat as the
  only source of truth

The agent is instructed to never invent experience, skills, or metrics, and to never
claim a PDF is attached until you have reviewed it.
